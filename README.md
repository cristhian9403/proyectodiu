Proyecto DIU es un sitio web interactivo desarrollado con tecnologías puras como HTML, CSS y JavaScript, enfocado en ofrecer prácticas básicas de inglés de manera dinámica y llamativa. A través de funciones interactivas, los usuarios pueden reforzar sus conocimientos de una forma divertida y accesible. Este proyecto destaca por su diseño intuitivo y su capacidad para ofrecer una experiencia de aprendizaje inmersiva, lo que lo convierte en una excelente herramienta tanto para principiantes como para aquellos que desean mejorar sus habilidades en inglés.
